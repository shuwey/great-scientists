# 小程序账号注册与备案 · 操作清单

> **为什么单独写一份**：注册 → 备案是整个项目**唯一不可压缩**的路径（管局 1–20 个工作日），
> 且步骤有严格顺序、几个地方填错就得等 7 天才能改。开发可以并行，这一步不能返工。

---

## 0. 先看五条结论

1. **一个小程序账号 = 一个唯一 AppID**，不能用别的账号的 AppID → 必须新注册。
   ★ **没有「在现有账号里添加一个小程序」的入口**（小程序之间是平行关系，不是父子）——
   唯一能"复用已有账号"的通道只对**已认证的企业 / 个体工商户公众号**开放，个人主体用不了。详见 §2。
2. 个人主体上限：**注册 5 个、备案 5 个**；同一邮箱只能注册 1 个；同一手机号 / 微信号各可绑定 5 个。
3. ★ **一件事定生死**：类目只报「**工具 > 信息查询**」，**名称和简介里都不要出现「教育」**——
   前者决定能否领成长计划的 6 个月免费云环境，后者会被备案入口直接拦下。
4. **顺序**：注册 → 填名称/类目 → 提交备案 → 报名成长计划领云环境 → 开发。
   （名称与类目填完，备案入口才出现；云环境要在开发前领，不是上线后。）
5. ⚠️ **备案绑在账号（AppID）上，不绑主体**。若之前的备案是给另一个 AppID 做的，本小程序要**重新备案**。

## 1. 材料准备（缺一不可）

| 材料 | 要求 | 常见卡点 |
|---|---|---|
| 邮箱 | **从未**注册/绑定过微信公众平台、开放平台、个人微信号 | 一个邮箱只能开 1 个小程序，用过的直接报错 |
| 身份证 | 有效期内，正反面彩色照 | 备案要求 > 1500×1100 px、< 200 KB |
| 实名微信 | 本人实名 + 已绑银行卡 | 用于扫码绑定管理员 + 人脸核身 |
| 手机号 | 能收短信，**备案期间保持畅通** | 平台/管局回访电话（常见 0755 开头）漏接会被驳回 |
| 通讯地址 | 精确到门牌号 | 北京地区**不要用** `#`、`-` 等特殊符号 |

---

## 2. 注册（约 10 分钟）

> ### ⚠️ 先破一个误解：没有「在现有账号里再加一个」这回事
>
> 一个小程序账号 = 一个小程序，账号之间**平行**，不存在"父账号下挂子小程序"。
> 登录着 A 小程序后台时，「立即注册」会被登录态遮住 ——
> **先退出登录**（右上角头像 → 退出），或用**无痕窗口**打开 `mp.weixin.qq.com`，才能看到注册入口。
> （社区里"已经有一个小程序了，找不到注册第二个的入口"绝大多数就是这个原因。）

### 2.1 你属于哪条路（先判路，再动手）

| 你手上有什么 | 走哪条路 | 说明 |
|---|---|---|
| 只有个人主体（现有小程序也是个人） | ★ **标准流程独立注册**（下方第 3 步起） | 没有捷径。身份证 / 管理员微信沿用，但**流程要完整走一遍**（含人脸核身） |
| 有**已认证**的企业 / 个体工商户公众号 | 公众号后台 →「广告与服务 › 小程序管理」→ 添加 → **快速注册并认证小程序** | 免 300 元认证费、免对公打款、免重交主体材料，几分钟完成；**邮箱仍需全新** |
| 只有**个人订阅号** | ❌ 用不了快速注册 | 个人订阅号无法微信认证，不满足"已认证企业/组织公众号"这个前提 |
| 用第三方平台（有赞 / 微盟等） | 走平台授权代注册 | 不是自建，本项目不适用 |

**无论走哪条，这两件事都不省**：

1. **邮箱必须全新**（从未注册/绑定过任何微信平台）；
2. **备案要在新账号上重做一次** —— 备案绑 **AppID**、不绑主体。

---

### 2.2 标准注册流程

1. 打开 `mp.weixin.qq.com` → 右上角「立即注册」→ 账号类型选 **小程序**（别选公众号）
2. 填新邮箱 + 密码 → 去邮箱点激活链接 / 回填 6 位验证码
3. 主体类型选 **个人**（★ 一经提交**不可修改**）
4. 填姓名 / 身份证号 / 手机号 → 管理员微信扫码 → **人脸核身**
   （白色或浅色干净背景，不戴帽子、口罩、耳机，不裸露上半身）
5. 完成后自动进入 mp 管理后台

## 3. 命名与类目（★ 最容易白跑的一步）

### 3.1 名称

- 长度 **4–30 字符**（1 个汉字 = 2 字符）。「读懂科学家」= 10 字符，合规。
- **禁用前置审批关键词**：`教育 / 培训 / 新闻 / 金融 / 直播 / 图书 / 出版 / 医疗 / 商城` 等；
  也不得含企业名义词（`公司 / 集团`）。
- 避免与已有小程序重名（系统会实时校验）。
- 改名代价：**7 天生效，每年仅 2 次** → 想好再填。

### 3.2 类目（只有一个正确答案）

| 选择 | 结论 | 原因 |
|---|---|---|
| **工具 > 信息查询** | ✅ **只报这一个** | 一石三鸟：成长计划允许、**虚拟支付要求工具类目**、术语检索是真实功能支撑 |
| 教育 > 教育信息展示 | ❌ 不要加 | 成长计划要求「类目**仅含**文娱/工具/社交/深度合成/资讯」，加教育 → 参与按钮置灰 → **丢 6 个月免费云环境**，还顺带丢虚拟支付资格 |
| 课程 / 视频 / 直播 / 社交类 | ❌ | 个人主体不开放，直接驳回 |

**个人可选的工具类二级类目只有这 11 个**（官方口径）：记账 / 日历 / 天气 / 办公 / 图片处理 / 计算器 /
报价比价 / **信息查询** / 预约报名 / 健康管理 / 备忘录 —— 我们只取「信息查询」。

⚠️ **「字典」不在个人可选范围内**，所以术语词典要归到「信息查询」，不要去选字典类目。

**怎么向审核员自证是"信息查询"**：398 条术语可检索、时间轴可按年份查 —— 讲查询能力，别讲"教学"。

⚠️ 工具类**明确不含「内容资讯分发」**（电商 / 社交 / 外卖 / 出行 / 游戏同理）。所以**首页与主导航必须以"查询"为主框架**、
阅读作为查询结果的延伸 —— 这既是过审要点，也是 v1 的信息架构约束。

### 3.3 简介（≤ 120 字）

建议：

```
科学家知识查询工具。收录 15 位科学家的生平时间轴与 398 条科学术语，支持关键词检索，适合中学生课外阅读使用。
```

**别写**「课程 / 教学 / 培训 / 报名」这类词。

## 4. 提交备案（今天就做）

**前置条件**：名称、头像、简介填完 **+** 类目选完，备案入口才可用。

1. mp 后台首页 →「小程序备案」→ 去备案
2. 填主体信息（身份证信息会自动识别，逐字核对一致）、小程序信息、上传材料
3. 互联网信息服务 / 前置审批项：不涉及则勾「以上都不涉及」；
   备案「服务内容」按实际运营选**非经营性**子项（这是通管局的分类，与平台类目是两回事）
4. 负责人人脸核身（须与小程序管理员一致）→ 提交 → 等**平台初审（1–2 工作日）**

**提交后两件不能忘的事**：

- ⏰ **工信部短信核验**：初审通过后会收到 **12381** 短信，**必须在 24 小时内**
  登录 `beian.miit.gov.cn` 完成核验；超时会被系统自动退回，得重新提交。
- 📞 **接回访电话**：平台与管局都可能来电核实，漏接会被驳回。

→ 管局审核 **1–20 个工作日** → 通过后下发备案号（记到 README 提审清单里）。

## 5. 认证 + 领云环境

1. **微信认证**（30 元/年，可选但建议）：认证后才获得「**被搜索 / 被分享**」能力 ——
   想靠微信搜索获客就靠它。未认证不影响版本发布。
2. **报名成长计划**：mp 后台 →「行业能力」→「AI 小程序成长计划」→ 参与计划
   → 按提示跳转腾讯云**领取 / 创建环境**。
   - 领到 **个人版环境，有效期 6 个月**；账号下已有云环境的可领大额抵扣券。
   - ★ 该计划**不要求小程序具备 AI 能力**。**别为拿资源去加 AI 功能** —— 个人主体上不了深度合成类目。
   - ⚠️ 若「参与计划」按钮置灰：先回头检查类目里是否混进了「教育」等非虚拟类目。
3. 建好环境后记住 **环境 ID**（形如 `cloud1-xxxxxxxx`）。
4. **（可选，建议一期就开）虚拟支付**：mp 后台 →「支付与交易 → 虚拟支付」→ 开通。
   条件：**身份证 + 工具类目 + 认证备案**，审核约 5 分钟，**月限额 10 万元**（Android 费率 1%、iOS 12%，腾讯 5% 限时免收）。
   开通后记下 `OfferID` 与现网 `AppKey`（在「虚拟支付 → 基本配置」），并在「道具管理」建商品（道具 ID + 价格）。
   ⚠️ 只能卖**工具型虚拟商品**（会员订阅 / 功能解锁 / 额度包），**不能卖课卖资料**。

## 6. 交接给开发（两个值）

| 值 | 填到哪 |
|---|---|
| **AppID**（`wx` 开头） | `miniapp/project.config.json` → `appid`（当前是 `touristappid`） |
| **环境 ID** | `miniapp/app.js` 顶部 → `CLOUD_ENV`（**留空也能跑**，云能力自动降级为本地档案） |

接着：

1. 微信开发者工具 → 右键 `cloudfunctions/login` → **上传并部署（云端安装依赖）**；`report` 同理
2. 云开发控制台 → 数据库 → 建集合 `users`、`progress`、`quizRecords`
3. 三个集合权限**全部设「仅创建者可读写」**（绝不设"所有人可读"）

## 7. 数量上限速查（个人主体）

| 项目 | 上限 |
|---|---|
| 注册小程序 | 5 个 |
| 备案小程序 | 5 个 |
| 单个邮箱可注册 | 1 个 |

> 注册或备案时若提示「当前主体已超过小程序注册数量上限」，说明 5 个额度用满了，
> 需要走主体变更或改用其他主体。
