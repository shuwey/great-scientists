5交互功能清单与位置

共 7 项交互，全部用原生 JS 实现，不引入任何框架，保证加载快、手机上不卡。

① 术语弹窗（核心功能）

出现位置：全站正文任意位置
  • 专业名词显示为虚线下划线的主色文字，鼠标悬停有轻微底色提示
  • 点击 → 居中弹窗：一句话通俗解释 + 一个生活类比 + （可选）一张小图
  • 弹窗底部固定两个出口：关闭 / 了解更多 →（跳转对应详解页）
  • 支持 ESC 关闭、点遮罩关闭；手机上改为底部抽屉，可下滑关闭

② 顶部导航 + 阅读进度条

出现位置：全站顶部，固定吸顶
  • 桌面端：Logo + 5 个栏目 + 搜索框；滚动时加毛玻璃背景和阴影
  • 移动端：折叠为汉堡菜单，点击展开全屏菜单
  • 导航条底部有一条 2px 进度条，随页面滚动增长

③ 时间轴节点展开

出现位置：timeline.html、首页预览区
  • 默认显示年份 + 一句话标题，点击展开 100–150 字详情 + 插图
  • 滚动进入视口时节点有淡入动画（尊重 prefers-reduced-motion）
  • 每个节点带"深入阅读 →"按钮，跳到对应详解页

④ 公式符号拆解

出现位置：详解页公式卡
  • 公式中每个符号（如 G、m、r）可单独点击
  • 点击后公式下方就地展开该符号的含义与单位，不打断阅读

⑤ 可交互演示

出现位置：labs.html + 各详解页"试一试"
  • 棱镜分光：拖动入射角看七色光分开
  • 引力滑块：改变质量/距离，看引力大小实时变化
  • 抛体运动：调整初速度与角度，看落点
  • 纯 Canvas 实现，无外部库，支持触屏拖动

⑥ 术语词典搜索

出现位置：glossary.html
  • 全站术语汇总，支持中文关键词实时过滤
  • 每个词条卡片点击查看完整解释，可跳转到相关详解页

⑦ 插图与图文配合

出现位置：全站
  • 统一插画风格：扁平线描 + 单色底 + 低饱和强调色（与站点主色同源的靛蓝/琥珀/青绿三色体系），不使用写实油画或 AI 生成人像，保证风格一致、无版权风险
  • 每张插图配一句话图注，说明"这张图在讲什么"
  • 图片全部本地化、带宽度自适应（srcset）与懒加载
万有引力✕

通俗解释：任何两个有质量的东西，都会互相吸引。质量越大吸得越狠，离得越远吸得越弱。

生活类比：你和同桌之间也有引力，只是你俩太轻了，这股力量小到完全感觉不到；换成地球这么大的家伙，就牢牢把你按在地面上了。
